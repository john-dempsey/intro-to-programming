Programming concepts

Adding to an array: push()

let bullets = [];          // starts empty
bullets.push(newBullet);   // adds newBullet to the end

push() adds an item to the end of an array, making it one longer. bullets.length is always the current number of items.

Removing from an array: splice()

bulletList.splice(i, 1);   // remove 1 item, starting at index i

splice(i, 1) removes the item at index i. Every item after it moves down one place to fill the gap, and the array gets one shorter:

Index 0Index 1Index 2
Before splice(0, 1)ABC
AfterBC

The trap: removing while looping forwards

Suppose all three bullets are off screen, and we loop forwards from i = 0:

iArray beforeChecksArray after
0A, B, CA: off screen, removeB, C
1B, CC: off screen, removeB
2Bloop ends (2 is not less than 1)B

B is never checked. When A was removed, B moved into index 0, but the loop had already moved on to index 1.

The fix: loop backwards

for (let i = bulletList.length - 1; i >= 0; i--) {

Starting at the end, removing an item only moves the items after it, which have already been checked. The items still to be checked never move. This is the standard way to remove items from an array while looping over it.

Arrays passed to a function are shared

removeOffScreenBullets(bullets);

When you pass an array to a function, the function gets the same array, not a copy. So when removeOffScreenBullets() splices bulletList, it's changing bullets. (Numbers are different: stage 3 showed that numbers are copied.) Because the function works on whatever array it's given, the tests can pass in their own arrays without touching the game's bullets.

Toggling a boolean: !

showDebug = !showDebug;

! means "not": !true is false and !false is true. Setting a boolean to its own opposite flips it, which is ideal for an on/off switch.

A debug overlay

A debug overlay is information drawn on screen for the developer, not the player, and switched on and off with a key. It shows what's happening inside the program while you play, without pausing it or filling the console. Here it shows the number of bullets in the array and the frame rate.
