Game 04 — Many Bullets

Exercises

Working copy: exercises/game-04-many-bullets/. Full instructions are in that folder's README.md. Press D in the game for the debug overlay.

  1. Predict, change, observe. Predict the most bullets you can have on screen at once, at two different speeds.
  2. Break it. Turn off removal and watch the overlay; replace push() with assignment.
  3. Debugger. Pause on splice() and watch an item being removed; use console.table().
  4. Write a test. Add cases where only the first or only the last bullet is off screen.
  5. Bug hunt. A bug you can't see by playing. Find it with the tests, then trace it on paper.
  6. Git. Put unfinished work aside with git stash, and bring it back with git stash pop.
  7. Challenge. Rewrite the removal using the array filter() method.
  8. Your project. Check how your project removes items, and add a debug overlay.
