Game 04 — Many Bullets

Sketch: src/game/04-many-bullets/sketch.js · Tests: src/game/04-many-bullets/tests.js

The player can now have many bullets on screen at once, stored in an array. Bullets are added to the array when fired and removed when they leave the top of the canvas. Pressing D shows a debug overlay.

You've used arrays since 10-array-of-balls, but always with a fixed number of items. This is the first time items are added and removed while the program runs. Removing items from an array inside a loop has a well-known trap, and this stage shows how the tests caught it.
