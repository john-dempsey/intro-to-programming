Game 04 — Many Bullets

Reading the sketch

Firing

function fireBullet() {
    let startY = ship.cannonTopY() - BULLET_HEIGHT / 2;
    let newBullet = new Bullet(ship.x, startY, BULLET_WIDTH, BULLET_HEIGHT, BULLET_SPEED, color(255));
    bullets.push(newBullet);
}

The "one at a time" check from stage 3 is gone; every press adds a bullet. The Bullet class hasn't changed at all.

Each frame

function updateBullets() {
    for (let i = 0; i < bullets.length; i++) {
        bullets[i].move();
        bullets[i].display();
    }

    removeOffScreenBullets(bullets);
}

Move and draw every bullet, exactly like the balls in sketch 11. The removal happens afterwards, in its own loop and its own function. Moving and drawing loops forwards safely, because nothing is removed while it runs.

Removing

function removeOffScreenBullets(bulletList) {
    for (let i = bulletList.length - 1; i >= 0; i--) {
        if (bulletList[i].isOffScreen()) {
            bulletList.splice(i, 1);
        }
    }
}

The loop starts at the last index (length - 1), keeps going while i is 0 or more, and counts down with i--.

Keys

function keyPressed() {
    if (key === " ") {
        fireBullet();
    } else if (key === "d" || key === "D") {
        showDebug = !showDebug;
    }
}

|| means "or", so D works whether or not Caps Lock is on.

The debug overlay

function displayDebugInfo() {
    push();
    fill(255, 255, 0);
    noStroke();
    textSize(14);
    text("bullets in array: " + bullets.length, 10, 20);
    text("frame rate: " + round(frameRate()), 10, 40);
    pop();
}

draw() only calls this when showDebug is true. push()/pop() stop the yellow fill and text size leaking into anything drawn afterwards.

The new tests

let mixed = [makeTestBullet(100), makeTestBullet(-50), makeTestBullet(-60), makeTestBullet(200)];
removeOffScreenBullets(mixed);
check("removes only the off-screen bullets", mixed.length, 2);
check("first survivor is the right bullet", mixed[0].y, 100);
check("second survivor is the right bullet", mixed[1].y, 200);

Checking the length isn't enough on its own: the function might remove the right number of bullets but the wrong ones. Checking each survivor's y proves the right ones were kept. The test arrays include an all-off-screen array, two off-screen bullets side by side, and an empty array: the cases most likely to go wrong.
