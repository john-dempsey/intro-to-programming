Reading the sketch

const diameter = 150;

const r = 255;
const g = 0;
const b = 100;
const opacity = 150;

const bg = 230;

function setup() {
    createCanvas(640, 360);
    background(bg);
}

function draw() {
}

function mousePressed() {
    noStroke();
    fill(r, g, b, opacity);       // was fill(255, 0, 100, 150)
    circle(mouseX, mouseY, diameter);  // was circle(mouseX, mouseY, 150)
}

function keyPressed() {
    background(bg);               // was background(230)
}

Every literal number sketch 03 used for diameter, colour and background has become a named global const, declared once above setup(). mousePressed() and keyPressed() are otherwise unchanged — they now read diameter, r/g/b/opacity, and bg instead of the numbers those names stand for.
