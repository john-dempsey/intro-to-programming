Reading the sketch

The constants

const UFO_SPEED = 2;          // pixels per frame
const UFO_POINTS = [50, 100, 150, 300];   // one is picked at random for each UFO
const UFO_MIN_WAIT = 15000;   // milliseconds from one UFO to the next: at least...
const UFO_MAX_WAIT = 25000;   // ...and at most

The Ufo class

Like a bullet, a UFO has a velocity, vx: positive when moving right, negative when moving left. Like everything else that can be hit, it has a getBounds() method. The interesting method is the one that decides when it has gone:

isOffScreen() {
    let halfWidth = this.ufoWidth / 2;
    if (this.vx > 0) {
        return this.x - halfWidth > width;
    }
    return this.x + halfWidth < 0;
}

It only checks the edge the UFO is heading for. A UFO starts just off the screen on the other side, so that edge is behind it and doesn't matter. One of the tests checks that a brand-new UFO isn't counted as gone before it has even appeared.

Sending one in

function spawnUfo() {
    let startX;
    let vx;
    if (random() < 0.5) {
        startX = -UFO_WIDTH / 2;           // from the left, heading right
        vx = UFO_SPEED;
    } else {
        startX = width + UFO_WIDTH / 2;    // from the right, heading left
        vx = -UFO_SPEED;
    }
    return new Ufo(startX, UFO_Y, UFO_WIDTH, UFO_HEIGHT, vx, random(UFO_POINTS));
}

random() with nothing in the brackets gives a number from 0 up to 1, so random() < 0.5 is true half the time: a coin toss.

Each frame

function updateUfo(now) {
    if (ufo === null) {
        if (now >= nextUfoTime) {
            ufo = spawnUfo();
            playSound(sounds.ufo);
        }
    } else {
        ufo.move();
        if (ufo.isOffScreen()) {
            removeUfo(now);
        }
    }
}

Either there's no UFO, and the question is "is one due?", or there is one, and it moves until it leaves.

Taking it away

function removeUfo(now) {
    ufo = null;
    scheduleNextUfo(now);
}

Called when the UFO flies off the screen, and when it's shot.

Shooting it

function handleUfoHit(now) {
    if (ufo === null) {
        return 0;
    }

    let ufosHit = collideBulletsWith(bullets, [ufo]);
    if (ufosHit.length === 0) {
        return 0;
    }

    let points = ufo.points;
    playSound(sounds.explosion);
    removeUfo(now);
    return points;
}
  • Stage 13's collideBulletsWith() works with any list of targets, so the UFO is put in a list of one: [ufo]. No new collision code was needed.
  • The points are saved in a variable before removeUfo(), because after it, ufo is null and has no points to read. Exercise 3 swaps these two lines to see what happens.

In updateGame()

let now = millis();
updateUfo(now);

The time is read once, near the top, and passed to everything that needs it. Further down, score += handleUfoHit(now); adds the UFO's points, if it was hit.

The debug overlay

When there's no UFO, the overlay counts down to the next one: (nextUfoTime - millis()) / 1000 turns the milliseconds left into seconds. When there is one, it shows how many points it's worth.

The new tests

  • testUfoMoves() and testUfoOffScreen(): movement in both directions, and leaving the screen at exactly the right moment, including where a UFO starts.
  • testScheduleNextUfo(): the time is random, so the test checks it's in the right range, with >= and <=.
  • testUfoArrivesOnTime(): no UFO at 4999 milliseconds, a UFO at 5000.
  • testUfoLeavesAndReschedules() and testShootingTheUfo(): both ways a UFO can go, and in both, the next one is scheduled.
