Game 11 — Title Screen and High Score

Sketch: src/game/11-title-screen/sketch.js · Tests: src/game/11-title-screen/tests.js · Plan: PLAN.md

A title screen, shown when the page loads and after every game, with the points for each row and the high score. The high score is saved in the browser, so it's still there next time.

That completes every "should have" feature in the plan. The updated PLAN.md has a "Progress" section recording what's done.

New ideas: a fourth game state, and a function that controls the moves between states; saving data with localStorage; and error handling with try/catch for something that can fail for reasons outside your control. The exercises look inside the browser's storage, go back in time with Git, and (for a challenge) use git bisect to find a bug.
