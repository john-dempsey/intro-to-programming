Reading the sketch

setup()

function setup() {
    createCanvas(CANVAS_WIDTH, CANVAS_HEIGHT);

    alienColours = [color(255, 80, 80), color(255, 180, 0), color(80, 200, 255), color(200, 120, 255)];
    highScore = loadHighScore(HIGH_SCORE_KEY);
    resetGame();

    runTests();

    // Set last, because some tests start a game of their own.
    gameState = STATE_TITLE;
}

The row colours are now a global, because the title screen draws one alien of each colour. The high score is loaded once. resetGame() doesn't reset it: it lasts between games.

draw()

if (gameState === STATE_TITLE) {
    displayTitleScreen();
} else {
    if (gameState === STATE_PLAYING) {
        updateGame();
    }
    drawGame();
}

On the title screen, the game isn't drawn at all. In every other state it's drawn, and only updated while playing.

The end of a game

function endGame() {
    newHighScore = score > highScore;
    if (newHighScore) {
        highScore = score;
        saveHighScore(HIGH_SCORE_KEY, highScore);
    }
}

score > highScore is a boolean, stored directly in newHighScore, which scoreSummary() uses to choose its message.

Loading safely

function loadHighScore(storageKey) {
    try {
        let saved = localStorage.getItem(storageKey);
        if (saved === null) {
            return 0;
        }

        let value = Number(saved);
        if (Number.isNaN(value)) {
            console.warn("The saved high score wasn't a number: " + saved);
            return 0;
        }
        return value;
    } catch (error) {
        console.warn("Couldn't load the high score: " + error.message);
        return 0;
    }
}

Three things can go wrong (nothing saved, something that isn't a number, storage not allowed) and each one gives a sensible answer: 0. The key is a parameter, so the tests can use their own key and never touch the player's real high score.

The title screen

for (let row = 0; row < ALIEN_ROWS; row++) {
    let rowY = 170 + row * 40;
    let sampleAlien = new Alien(width / 2 - 60, rowY, ALIEN_WIDTH, ALIEN_HEIGHT, alienColours[row], ALIEN_ROW_POINTS[row]);
    sampleAlien.display();
    fill(255);
    text("= " + sampleAlien.points + " POINTS", width / 2 - 30, rowY);
}

The title screen reuses the Alien class to draw one alien per row, next to its value. If the colours or points change, the title screen changes with them.

The new tests

testEnterChangesState() has one check per row of the state table. testHighScoreStorage() saves and loads with a test-only key, including the "not a number" case, and removes the key at the end.
