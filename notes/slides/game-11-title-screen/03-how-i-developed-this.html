Game 11 — Title Screen and High Score

How I developed this

Planning the states on paper

Before writing code, I drew the four states as boxes with arrows between them, labelled with what causes each move. That drawing became the table on the concepts page, then handleEnter(), then the tests: one check per arrow.

The title screen that never appeared

My first handleEnter() had two separate ifs. After a game, Enter went straight into a new game, and the title screen never showed. A logpoint on the first line of handleEnter() printed the state once per press, so handleEnter() wasn't being called twice. Stepping through it showed both ifs running in the same call: the first set the state to title, then the second saw title and started a game. Changing the second if to else if fixed it. This is the stage's bug hunt.

Testing without wiping my own high score

The first version of loadHighScore() and saveHighScore() always used the real key. My test saved 120, and my real high score was replaced with 120. So I made the key a parameter: the game passes HIGH_SCORE_KEY, and the test passes a test-only key that it deletes at the end.

Checking the error handling actually works

The catch blocks only run when something goes wrong, so normal play never tests them. To check them, I temporarily added throw new Error("Storage is switched off"); inside each try, finished a game, and checked that a warning appeared and the game carried on. Then I removed the throw. I also used DevTools' Application tab to edit the saved value to hello, which is how I found I needed the Number.isNaN() check: without it, the title screen said "HIGH SCORE NaN".

Updating the plan

This finished the "should have" list, so I added a "Progress" section to PLAN.md. The plan had said "start screen and game-over screen"; the game-over screen already existed, so I noted what this stage added instead.

Manual checks

  • The page opens on the title screen, showing four aliens and their points.
  • Enter starts a game; Enter during a game does nothing.
  • After a game, the message shows the score, and says when it's a new high score.
  • Enter after a game goes to the title screen, showing the updated high score.
  • Reloading the page keeps the high score.
  • In a private window, the game still works.
  • The console shows only PASS lines and the one expected warning.
