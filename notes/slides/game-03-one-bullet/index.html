Game 03 — Firing a Bullet

Sketch: src/game/03-one-bullet/sketch.js · Tests: src/game/03-one-bullet/tests.js

Pressing space fires a bullet from the ship's cannon. Only one bullet can be on screen at a time, as in the original arcade game.

The Bullet class is built the same way as Ship. What's new is null, for "there's no bullet right now"; keyPressed() working alongside keyIsDown(); and a method that returns true or false. The exercises use the console to inspect the running game, the debugger's Call Stack and Step into, and Git's staging area.
