Game 03 — Firing a Bullet

Exercises

Working copy: exercises/game-03-one-bullet/. Full instructions are in that folder's README.md.

  1. Predict, change, observe. Does the bullet follow the ship? Very slow and very fast bullets. Why do some presses do nothing?
  2. The console as a calculator. Inspect and change ship and bullet while the game runs.
  3. Break it. Never reset bullet to null; fire with keyIsDown() instead of keyPressed().
  4. Debugger. Use the Call Stack, Step into and the Watch panel.
  5. Write a test. Is a bullet far below the canvas "off screen"? Decide, test and justify. Test that bullets start at the ship.
  6. Bug hunt. One wrong character causes two different symptoms.
  7. Git. Use git add on one file at a time to split changes into two commits.
  8. Your project. Sort your project's actions into once-per-press and while-held.
