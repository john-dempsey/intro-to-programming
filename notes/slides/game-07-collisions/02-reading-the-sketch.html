Reading the sketch

Bounds

All three classes get a getBounds() method in the same pattern: half the width either side of x, half the height either side of y. The ship's bounds cover only its body, not its cannon; the comment explains why.

Handling collisions

function handleCollisions(bulletList, alienList) {
    for (let bulletIndex = bulletList.length - 1; bulletIndex >= 0; bulletIndex--) {
        let bulletBounds = bulletList[bulletIndex].getBounds();

        for (let alienIndex = 0; alienIndex < alienList.length; alienIndex++) {
            if (boundsOverlap(bulletBounds, alienList[alienIndex].getBounds())) {
                bulletList.splice(bulletIndex, 1);
                alienList.splice(alienIndex, 1);
                break;   // this bullet is gone: stop checking it against other aliens
            }
        }
    }
}

The loop variables are bulletIndex and alienIndex, not i and j. With two arrays and two loops, it's very easy to write bulletList[alienIndex] by mistake; the long names make that mistake look wrong.

The bullet's bounds are worked out once, before the inner loop, rather than once for every alien.

In draw()

alienDirection = marchAliens(aliens, alienDirection);
displayAliens();
updateBullets();
handleCollisions(bullets, aliens);

Collisions are checked after everything has moved. Because formationAtEdge() loops over whichever aliens are left, destroying a whole edge column automatically lets the formation travel further. No extra code was needed for that.

Drawing hitboxes

function displayBounds(bounds) {
    push();
    noFill();
    stroke(255, 255, 0);
    rectMode(CORNERS);
    rect(bounds.left, bounds.top, bounds.right, bounds.bottom);
    pop();
}

rectMode(CORNERS) changes what rect()'s arguments mean: two opposite corners, instead of a corner and a size. That matches the bounds object exactly.

The new tests

let square = { left: 0, right: 10, top: 0, bottom: 10 };

let touchingRight = { left: 10, right: 20, top: 0, bottom: 10 };
check("touching along an edge", boundsOverlap(square, touchingRight), false);

let sameColumnBelow = { left: 5, right: 15, top: 50, bottom: 60 };
check("overlap in x only", boundsOverlap(square, sameColumnBelow), false);

Because boundsOverlap() takes plain objects, the tests can use simple hand-written rectangles with no ship, bullet or alien involved. The handleCollisions() tests then check the bigger picture: a hit removes both, a miss removes neither, the right alien is removed, and one bullet can't destroy two aliens.
