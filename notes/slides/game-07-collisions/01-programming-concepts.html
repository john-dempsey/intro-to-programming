Programming concepts

A method that returns an object

getBounds() {
    return {
        left: this.x - this.alienWidth / 2,
        right: this.x + this.alienWidth / 2,
        top: this.y - this.alienHeight / 2,
        bottom: this.y + this.alienHeight / 2
    };
}

The object literal from sketch 06, built and returned in one go. The ship, bullets and aliens each store their size differently (bodyWidth, bulletWidth, alienWidth), but all three have a getBounds() method that answers in the same shape: left, right, top, bottom. Code that only needs a rectangle doesn't have to know which kind of object it came from.

When do two rectangles overlap?

Two rectangles overlap only if they overlap left-to-right and top-to-bottom at the same time. Left-to-right, they overlap if each one's left edge is to the left of the other's right edge:

let overlapX = first.left < second.right && first.right > second.left;
let overlapY = first.top < second.bottom && first.bottom > second.top;
return overlapX && overlapY;

Try it on squared paper. Two rectangles in the same column overlap in x but not in y: no hit. Two in the same row overlap in y but not in x: no hit. Only when both are true do they actually cover some of the same squares. Giving each half a name (overlapX, overlapY) makes the final line read like the sentence above.

The test uses < and >, not <= and >=, so rectangles that only touch along an edge don't count. That's a decision, and the tests record it.

Removing from two arrays: backwards and break

Every bullet has to be checked against every alien: a nested loop. When there's a hit, one item is removed from each array:

  • The outer loop (bullets) goes backwards, for the same reason as stage 4: items are removed from the array it's looping over.
  • The inner loop (aliens) can go forwards, because as soon as it removes an alien, break ends it. It never carries on past a removal, so nothing gets skipped.

break

break ends the loop it's in immediately; the program carries on after the loop. Here, once a bullet has hit an alien, the bullet is gone, so there's no point checking it against the remaining aliens. Without break, the removed bullet would carry on and destroy every other alien it was touching. Compare this with return in stage 6, which ends the whole function, not just the loop.

Hitboxes

A hitbox is the shape the program uses for collisions, which isn't necessarily the shape that's drawn. Drawing hitboxes in the debug overlay shows exactly what the collision code "sees". If a hit looks unfair, the overlay shows you why.
