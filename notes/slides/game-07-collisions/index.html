Game 07 — Collisions

▶︎ Run this sketch Sketch: src/game/07-collisions/sketch.js · Tests: src/game/07-collisions/tests.js

A bullet that hits an alien destroys both. For the first time, the game can actually be played: shoot the aliens before they reach you. There's no win or lose yet; that's stage 8.

The collision test is the rectangle-overlap test from the Frogger capstone. What's new is how it's organised: each object can describe the rectangle around it, as an object literal (sketch 06), and one small function decides whether two rectangles overlap. Removing items from two arrays at once brings back stage 4's backwards loop, plus break. The debug overlay now draws every hitbox.
