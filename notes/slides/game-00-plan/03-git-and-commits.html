Game 00 — The Plan

Git and commits

A commit is a save point

Each commit records exactly what every file looked like at that moment. If a later change breaks everything, you can see what changed since the last working commit, or go back to it.

That's why every stage ends with a commit. The commit history becomes a list of working versions of the game, one per stage.

The commands you'll use most

CommandWhat it does
git statusLists the files that have changed since the last commit
git diffShows the exact lines that changed
git add .Includes every changed file in the next commit
git commit -m "message"Makes the commit, with a message
git log --onelineLists past commits, one per line

Good commit messages

A message should say what changed, briefly, so that someone reading git log in six months can follow the history:

UnhelpfulBetter
stuffGame stage 1: draw the ship
fixed itStop ship going past right edge
changesAdd tests for ship movement
