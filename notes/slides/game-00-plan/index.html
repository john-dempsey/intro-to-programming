Game 00 — The Plan

▶︎ Run this sketch Sketch: src/game/00-plan/sketch.js · Plan: src/game/00-plan/PLAN.md

Sketches 01–13 each introduced one programming idea. This series is different: it's a worked example of how to develop a program, from an idea to a finished game, one small stage at a time. The game is a simple version of Space Invaders.

You won't build this game yourself — your own project is where you do that. Instead, read how each stage was developed, then do that stage's exercises. The exercises practise the skills you'll need for your project: planning, testing, debugging and using Git. Each stage's exercises start from fresh code, so nothing you change carries over to the next stage.

Stage 0 has no game code at all. It's the plan.

Every stage has the same pages: the new ideas it uses, a walkthrough of the code, a How I developed this page describing the decisions, mistakes and fixes along the way, and the exercises.
