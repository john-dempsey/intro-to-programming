How p5 works

No new p5 mechanics — ball is an ordinary JavaScript object, built entirely by this sketch's own code. p5's functions are simply called with its properties (ball.x, ball.col, ...) exactly as they were called with separate variables before; p5 has no idea ball exists as a single object.
