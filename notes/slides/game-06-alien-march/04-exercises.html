Exercises

Working copy: exercises/game-06-alien-march/. Full instructions are in that folder's README.md.

  1. Predict, change, observe. A bigger drop, a faster march (is the code or the test wrong?), and the direction on the overlay.
  2. Break it. Recreate the "slide down the edge" bug two different ways; remove the drop.
  3. Debugger. Find which alien hit the edge; use a logpoint instead of console.log().
  4. Write a test. An empty formation; a regression test for the left edge.
  5. Bug hunt. The aliens march off one edge but not the other.
  6. Git. Undo a commit safely with git revert.
  7. Challenge. Make the aliens jump every 30 frames, as in the original game.
  8. Your project. Group decisions, and checking where something is about to be.
