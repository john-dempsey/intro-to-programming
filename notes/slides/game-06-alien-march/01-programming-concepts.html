Game 06 — The Alien March

Programming concepts

Group behaviour: one decision for everyone

In sketch 13, each ball checked its own position and reversed its own velocity. That's right for balls, which move independently. The aliens move as one formation, so the decision "should we turn round?" is made once, for the whole group, and then every alien does the same thing.

So the direction isn't stored in each alien. There's one variable for the whole formation:

let alienDirection = 1;   // 1 = formation moving right, -1 = moving left

"Is any item...?": searching with an early return

for (let i = 0; i < alienList.length; i++) {
    if (/* this alien is at an edge */) {
        return true;   // one alien is enough: no need to check the rest
    }
}
return false;          // only reached if no alien was at an edge

return ends the whole function immediately, even from inside a loop. As soon as one alien is found at an edge, the answer is true and there's no need to check the others. return false is after the loop, so it's only reached once every alien has been checked. Putting return false inside the loop is a common mistake: the function would give up after checking only the first item.

Looking ahead

The edge check asks where each alien is about to be (x plus one step), not where it is now. That way the formation turns round before any alien crosses the edge, so the aliens never end up past the edge at all. The "How I developed this" page shows what goes wrong without this.

A function that returns the new value

alienDirection = marchAliens(aliens, alienDirection);

marchAliens() is given the current direction and returns the direction for the next frame. It doesn't change the global variable itself; the caller stores the result. That means a test can give it any formation and any direction, and check exactly what comes back, without touching the game.

|| in a condition

if (nextX - halfWidth < 0 || nextX + halfWidth > width) {

"Past the left edge or past the right edge." One check covers both directions, so the same function works whichever way the formation is moving.
