How I developed this

Attempt 1: reuse the bounce from sketch 13

The aliens bounce off the edges, so I copied the idea from sketch 13: each alien got its own vx, and its own move() reversed vx when it hit an edge.

It looked fine for about three seconds. Then the rightmost column hit the edge and turned round, while the other seven columns carried on. The rightmost aliens marched straight back through their neighbours, and soon the formation was a mess of aliens overlapping and crossing each other.

The code did exactly what I'd written: each alien bounced on its own. The problem was the design, not a typing mistake. The formation needs to make one decision for all of its aliens. I moved the direction out of the aliens into a single alienDirection, and wrote formationAtEdge() to check the whole group.

Attempt 2: the aliens slide down the edge

My first formationAtEdge() checked where each alien was:

let nextX = alienList[i].x;   // where the alien is now

When the formation reached the right edge, it didn't turn round. It slid straight down the edge and off the bottom of the screen in a couple of seconds.

To find out why, I set a breakpoint on the return -direction; line and watched direction. It paused every single frame, with direction alternating between 1 and -1. Stepping through showed the sequence:

  1. An alien moves one pixel past the edge.
  2. Next frame: it's past the edge, so everyone drops and the direction flips to -1.
  3. Next frame: dropping didn't move anyone sideways, so the alien is still past the edge. Drop again, and flip back to 1.
  4. And so on, every frame, all the way down.

Checking where each alien is about to be fixed it. The formation now turns round before any alien crosses the edge, so after a drop no alien is ever past it.

Writing the tests for the bugs

After each fix, I wrote a test that would have caught the bug: testWholeFormationTurns() for attempt 1, and the "next step doesn't drop again" checks in testMarchAtEdge() for attempt 2. If a later change brings either bug back, a test will fail straight away.

Manual checks

  • The formation moves right, and turns round when the rightmost column reaches the edge, without crossing it.
  • It drops by the same amount at every turn, once per turn.
  • The same at the left edge, with the leftmost column.
  • The gaps between aliens never change.
  • The debug overlay's direction switches between 1 and -1 at each edge.
  • The ship and bullets still work while the aliens move.
  • The console shows only PASS lines.
