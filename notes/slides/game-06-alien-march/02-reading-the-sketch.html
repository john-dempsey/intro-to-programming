Reading the sketch

Moving an alien

moveBy(dx, dy) {
    this.x += dx;
    this.y += dy;
}

The alien doesn't decide where to go; it moves by whatever it's told. dx and dy are short for "change in x" and "change in y", a common naming convention.

Is the formation at an edge?

function formationAtEdge(alienList, direction) {
    for (let i = 0; i < alienList.length; i++) {
        let nextX = alienList[i].x + direction * ALIEN_SPEED;
        let halfWidth = alienList[i].alienWidth / 2;

        if (nextX - halfWidth < 0 || nextX + halfWidth > width) {
            return true;
        }
    }
    return false;
}

For each alien, work out where it will be after one more step, and check that position's edges against the canvas, as the ship's clamp did in stage 2.

Marching

function marchAliens(alienList, direction) {
    if (formationAtEdge(alienList, direction)) {
        for (let i = 0; i < alienList.length; i++) {
            alienList[i].moveBy(0, ALIEN_DROP);
        }
        return -direction;
    }

    for (let i = 0; i < alienList.length; i++) {
        alienList[i].moveBy(direction * ALIEN_SPEED, 0);
    }
    return direction;
}

Two possibilities each frame. At an edge: every alien drops, and the direction is reversed (-direction turns 1 into -1 and -1 into 1). Otherwise: every alien moves one step sideways, and the direction stays the same. Each path ends with its own return, so only one of them ever runs.

In draw()

alienDirection = marchAliens(aliens, alienDirection);
displayAliens();

March first, then draw, so what's on screen is always the aliens' latest position.

The new tests

// The next step, in the new direction, should move left and NOT drop
// again. (If it drops again, the aliens slide down the edge.)
newDirection = marchAliens(formation, newDirection);
check("next step keeps the new direction", newDirection, -1);
check("next step moves left", formation[0].x, width - 15 - ALIEN_SPEED);
check("next step doesn't drop again", formation[0].y, 100 + ALIEN_DROP);

This test checks two frames in a row: the turn at the edge, and the frame after. Each of the bugs on the next page was added to the tests once it was found, so it can't come back without a FAIL. A test written for a bug you've already fixed is called a regression test.
