Game 05 — A Grid of Aliens

Programming concepts

Nested loops

for (let row = 0; row < rowCount; row++) {
    for (let column = 0; column < columnCount; column++) {
        // runs once for every (row, column) pair
    }
}

The inner loop runs all the way through every time the outer loop goes round once. With 4 rows and 8 columns, the inside runs 4 × 8 = 32 times: row 0 with columns 0 to 7, then row 1 with columns 0 to 7, and so on.

Naming the loop variables row and column rather than i and j makes it much harder to mix them up.

A grid in a single array

The 32 aliens are stored in one ordinary array, row by row:

Column 0Column 1…Column 7
Row 0index 0index 1…index 7
Row 1index 8index 9…index 15
Row 2index 16index 17…index 23
Row 3index 24index 25…index 31

JavaScript can also store a grid as an array of arrays (a 2D array). That's useful when you often need "the alien at row 2, column 5". This game mostly needs "every alien", to move, draw and check them all, so a single array keeps every loop simple.

Position from row and column

let x = ALIEN_GRID_LEFT + column * ALIEN_SPACING_X;
let y = ALIEN_GRID_TOP + row * ALIEN_SPACING_Y;

Each column is one spacing further right; each row is one spacing further down. Column 0 is at ALIEN_GRID_LEFT exactly. The column decides x and the row decides y, which is easy to get backwards.

A function that builds and returns an array

aliens = createAlienGrid(ALIEN_ROWS, ALIEN_COLUMNS, rowColours);

Like createBall() in sketch 07, createAlienGrid() builds something and hands it back with return. Because it takes the sizes as parameters, the tests can ask for a small 2 × 3 grid whose positions are easy to work out by hand.

Repeating a list with %

let alienColour = colourList[row % colourList.length];

% gives the remainder after dividing (sketch 12). With 4 colours, rows 0–3 get colours 0–3, then row 4 gets 4 % 4 = 0, the first colour again. This handles an edge case: more rows than colours.

Checking every item in a test

testAliensFitOnCanvas() loops over all 32 aliens and counts how many are outside the canvas, then makes one check that the count is 0. One PASS line instead of 32 keeps the console readable, and when it fails it prints which aliens are wrong.
