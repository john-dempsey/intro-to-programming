Game 05 — A Grid of Aliens

How I developed this

One alien first

I didn't start with the grid. I drew a single alien in the middle of the screen, adjusted its eyes until it looked right, and committed. Only then did I build the grid. If something looked wrong in the grid, I already knew the alien itself was fine, so the problem had to be in the loop.

Decision: one array, not a 2D array

A grid of aliens sounds like a 2D array, and I considered one. But I thought about what the next stages need to do: move every alien (stage 6), check every alien against every bullet (stage 7), and count the aliens left (stage 8). All of those are "every alien", which is one simple loop over a single array. A 2D array would need a nested loop every time. When aliens are destroyed, removing one from a single array is also easier than leaving a gap in a 2D one.

The bug: a diagonal of aliens

My first grid showed only four aliens, in a diagonal staircase. The debug overlay said aliens in array: 32, so they were all there: some were drawn on top of each other. The failing test said:

FAIL: second alien is one column right (expected 130, got 80)

So x wasn't changing along a row. I'd typed row where I meant column in the x calculation. Every alien in a row had the same x, so all eight were drawn in the same place. The exercises' bug hunt is the same mistake.

That's why the loop variables are called row and column and not i and j: x = ... + row * ... looks wrong when you read it back; x = ... + i * ... doesn't.

Adjusting the layout

With the overlay on, its text overlapped the top-left alien. I moved the grid down by changing one constant, ALIEN_GRID_TOP, and every test still passed because they use the constants rather than fixed numbers. I also checked there's room for the grid to march sideways in stage 6: it's 380 pixels wide on a 640-pixel canvas.

Manual checks

  • Four rows of eight, evenly spaced, each row a different colour.
  • Every alien has two eyes, in the same place.
  • The debug overlay doesn't cover any aliens, and shows 32.
  • Bullets still fire, and pass through the aliens (expected, for now).
  • The console shows only PASS lines.
