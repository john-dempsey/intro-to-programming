Game 05 — A Grid of Aliens

Exercises

Working copy: exercises/game-05-alien-grid/. Full instructions are in that folder's README.md.

  1. Predict, change, observe. More rows, more columns (will it fit?), and closer spacing.
  2. Break it. Swap the nested loops (is that a bug?); delete return and read the error message.
  3. Debugger. Predict row, column, x and y at each pause in a nested loop; jump to one alien with a conditional breakpoint.
  4. Write a test. Write and test an alienAt(row, column) function.
  5. Bug hunt. 32 aliens in the array, but only four on screen.
  6. Git. See the history of one file with git log -- sketch.js and git show.
  7. Your project. Look for repeated code a nested loop could replace; write a "fits on the canvas" test.
