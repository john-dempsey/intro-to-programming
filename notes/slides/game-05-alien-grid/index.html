Game 05 — A Grid of Aliens

Sketch: src/game/05-alien-grid/sketch.js · Tests: src/game/05-alien-grid/tests.js

Four rows of eight aliens, each row in its own colour. The aliens don't move yet, and bullets pass straight through them.

The Alien class is built like Ship and Bullet. The grid is made with a nested loop, which you met in the grid exercises from sketch 10 (exercises/create/10-square-grid). New here: storing a grid in a single array, a function that builds and returns an array, and a test that checks every item in a loop. The exercises cover reading error messages, debugging inside a nested loop, and Git's history of a single file.
