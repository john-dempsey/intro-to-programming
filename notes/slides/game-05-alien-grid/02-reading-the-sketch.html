Game 05 — A Grid of Aliens

Reading the sketch

The Alien class

display() {
    let eyeSize = this.alienHeight / 4;
    let eyeOffsetX = this.alienWidth / 5;
    let eyeOffsetY = -this.alienHeight / 8;

    push();
    translate(this.x, this.y);
    rectMode(CENTER);
    noStroke();
    fill(this.col);
    rect(0, 0, this.alienWidth, this.alienHeight, 4);   // body, rounded corners
    fill(BACKGROUND_COLOUR);
    rect(-eyeOffsetX, eyeOffsetY, eyeSize, eyeSize);     // left eye
    rect(eyeOffsetX, eyeOffsetY, eyeSize, eyeSize);      // right eye
    pop();
}

The same pattern as Ship: translate to the alien's centre, then draw around (0, 0). The eyes are filled with the background colour, so they look like holes. The fifth argument to rect() rounds the corners.

Building the grid

function createAlienGrid(rowCount, columnCount, colourList) {
    let grid = [];

    for (let row = 0; row < rowCount; row++) {
        for (let column = 0; column < columnCount; column++) {
            let x = ALIEN_GRID_LEFT + column * ALIEN_SPACING_X;
            let y = ALIEN_GRID_TOP + row * ALIEN_SPACING_Y;
            let alienColour = colourList[row % colourList.length];
            grid.push(new Alien(x, y, ALIEN_WIDTH, ALIEN_HEIGHT, alienColour));
        }
    }

    return grid;
}

Start with an empty array, add one alien for every row and column, and return the full array.

In setup()

let rowColours = [color(255, 80, 80), color(255, 180, 0), color(80, 200, 255), color(200, 120, 255)];
aliens = createAlienGrid(ALIEN_ROWS, ALIEN_COLUMNS, rowColours);

The colours are made in setup() because p5's color() only works once the sketch has started.

The new tests

// A 2 x 3 grid is stored row by row:
//   index 0, 1, 2  = top row, left to right
//   index 3, 4, 5  = second row, left to right
function testAlienGridPositions() {
    let grid = createAlienGrid(2, 3, [color(255)]);

    check("first alien x", grid[0].x, ALIEN_GRID_LEFT);
    check("second alien is one column right", grid[1].x, ALIEN_GRID_LEFT + ALIEN_SPACING_X);
    check("fourth alien starts the second row (y)", grid[3].y, ALIEN_GRID_TOP + ALIEN_SPACING_Y);
    // ...
}

The tests use a small grid and check the alien at each "interesting" place: the first, the next one along, the start of the second row and the last. The expected values are written using the constants, so the tests still pass if you change the spacing.
