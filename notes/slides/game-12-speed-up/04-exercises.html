Exercises

Working copy: exercises/game-12-speed-up/. Full instructions are in that folder's README.md. Press D in the game: the overlay now shows the aliens' speed.

  1. Predict, change, observe. Predict the speed with 16 aliens left; try other top speeds.
  2. The console. See for yourself that 0.1 + 0.2 isn't 0.3.
  3. Break it. Swap a checkClose() for check(); fix the speed at 32 aliens and see which tests notice.
  4. Debugger. A conditional breakpoint that pauses once the aliens are fast; watch the speed change.
  5. Write a test. Check every number of aliens from 0 to 32, and decide what should happen at 0.
  6. Bug hunt. The aliens are behaving oddly: read map()'s values carefully.
  7. Git. git blame and git log -S: who changed this line, and when?
  8. Playtest. Watch someone else play, then change one constant.
  9. Your project. Could your project get harder as it goes on? Do any of your tests compare decimals with ===?
