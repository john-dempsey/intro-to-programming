Game 12 — The Aliens Speed Up

▶︎ Run this sketch Sketch: src/game/12-speed-up/sketch.js · Tests: src/game/12-speed-up/tests.js

The first "could have" feature in the plan. The aliens start slowly and march faster as their numbers fall, until the last one races from side to side. Only a few lines of the game change, but this is the stage that makes it feel tense.

New ideas: p5's map(), which turns a number from one range into another; giving a function a value it used to read from a constant, so the value can change while the game runs; and why decimal numbers can't always be compared with ===. The exercises use git blame to find out who last changed a line, and ask you to watch someone else play your game.
