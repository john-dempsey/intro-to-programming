How I developed this

A branch, and a constant that disappeared

git switch -c speed-up

I started by replacing ALIEN_SPEED with the two new constants. The game stopped working, and the console said:

A test crashed: ALIEN_SPEED is not defined

Removing a constant is like changing a function's parameters (stage 9): everything that used it has to change too. I searched the project for ALIEN_SPEED (Ctrl+Shift+F in VS Code) and found it in marchAliens(), formationAtEdge() and two of the march tests. I added the speed parameter to both functions, passed it everywhere they were called, and ran the tests again before going any further.

Aliens that slowed down

Next I wrote alienSpeedFor() and its tests. Three tests failed at once:

FAIL: full grid marches at the start speed (expected 1, got 4)
FAIL: one alien left marches at top speed (expected 4, got 1)
FAIL: fewer aliens march faster (expected true, got false)

The game agreed: the aliens raced at the start and crawled at the end. I'd written the last two values of map() the wrong way round:

return map(aliensLeft, fullGrid, 1, ALIEN_TOP_SPEED, ALIEN_START_SPEED);

Reading the p5 reference again, the values go in pairs: fullGrid goes with the start speed. Swapping the last two fixed it. This is the stage's bug hunt.

The tests found this before I'd played a single game. Testing both ends of a range is cheap, and catches exactly this kind of mix-up.

Tuning the top speed

My first top speed was 6. I could beat the game, but only because I knew it was coming. I asked someone else to play three games without any help from me. They never hit the last alien, and gave up. I tried 3 next: the end of the game felt flat. 4 was hard but fair. I only changed the constant; no other line of code was touched.

Manual checks

  • With a full grid, the aliens march at the same speed as in stage 11.
  • They speed up a little with every alien destroyed (watch the overlay).
  • The last alien is fast, but can be hit.
  • Even at top speed, the formation turns at the edges without crossing them.
  • A new game starts slow again.
  • The console shows only PASS lines.
