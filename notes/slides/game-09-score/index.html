Game 09 — Score

Sketch: src/game/09-score/sketch.js · Tests: src/game/09-score/tests.js

The first of the plan's "should have" features: a score. Each alien is worth points depending on its row (30, 20, 20 and 10, top to bottom), shown in the top-right corner and in the end-of-game message.

From now on, every stage improves a game that already works. That changes how features are added: each one is built on its own Git branch and merged into main when it's finished, so the working game on main is never broken by a half-finished feature.

New ideas: changing what a function returns, and the knock-on effects of changing a function's parameters. The bug in this stage's story is one the tests didn't catch.
