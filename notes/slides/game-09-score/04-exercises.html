Game 09 — Score

Exercises

Working copy: exercises/game-09-score/. Full instructions are in that folder's README.md.

  1. Predict, change, observe. Work out the highest possible score; fewer point values than rows.
  2. The console. Inspect aliens' points; total the remaining points with a loop.
  3. Break it. Remove the return (what's NaN?); leave out an argument and read the error.
  4. Debugger. Use the Watch panel and Step out.
  5. Write a test. Points on the real grid; what makes drawing hard to test?
  6. Bug hunt. Every test passes, but the score is wrong. Then make the buggy line testable.
  7. Git. Build a small feature on a branch, merge it, delete the branch.
  8. Your project. Test your project's counters; build the next feature on a branch.
