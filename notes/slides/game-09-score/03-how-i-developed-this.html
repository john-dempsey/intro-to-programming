How I developed this

A branch for the feature

Before writing anything, I made a branch:

git switch -c score

Everything below happened on that branch. main kept the stage 8 game, working, the whole time.

The parameter I forgot to pass

I added pointsList to createAlienGrid() and updated the call in resetGame(). When I ran the game, the tests crashed:

A test crashed: Cannot read properties of undefined (reading 'length')

The tests called createAlienGrid() with three arguments, so pointsList was undefined, and pointsList.length failed. The error was reported inside createAlienGrid(), but the cause was in the tests. I searched the project for createAlienGrid( (Ctrl+Shift+F in VS Code) and found four calls in tests.js that needed updating.

Whenever you change a function's parameters, search for every call to it.

The bug the tests missed

With the tests passing, I played the game. The score flickered: it showed 10 or 20 for a moment after a hit, then went back to 0. Every test passed.

I added score to the debugger's Watch panel and stepped through updateGame(). The line was:

score = handleCollisions(bullets, aliens);

= instead of +=. Every frame, the score was replaced by that frame's points, which is usually 0. One character.

The tests didn't catch it because they test handleCollisions(), which was correct. The bug was in the line that uses it, inside updateGame(), which no test calls. Tests only check the code they actually run. The bug hunt in this stage's exercises is this same bug, and asks how you could make that line testable.

Manual checks

  • The score starts at 0, top right.
  • Each row scores what it should: 30, 20, 20, 10.
  • The score keeps growing, and never drops back.
  • A perfect game scores 640.
  • The end-of-game message shows the final score.
  • Enter starts a new game with a score of 0.
  • The console shows only PASS lines.

The commits, and the merge

git commit -am "Add points to aliens, by row"
git commit -am "handleCollisions returns points; show score"
git commit -am "Fix score being replaced instead of added to"
git switch main
git merge score
git branch -d score

Nothing had changed on main while I worked, so the merge was a fast-forward: Git just moved main forward to include the three new commits.
