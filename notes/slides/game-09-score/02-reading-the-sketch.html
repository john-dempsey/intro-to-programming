Scoring a hit

function handleCollisions(bulletList, alienList) {
    let pointsScored = 0;

    for (/* every bullet, backwards */) {
        for (/* every alien */) {
            if (boundsOverlap(/* ... */)) {
                pointsScored += alienList[alienIndex].points;
                bulletList.splice(bulletIndex, 1);
                alienList.splice(alienIndex, 1);
                break;
            }
        }
    }

    return pointsScored;
}

The points are added up before the alien is spliced out. After the splice, alienList[alienIndex] would be a different alien, or nothing at all.

Resetting and showing the score

resetGame() sets score = 0, drawGame() calls displayScore(), and both end-of-game messages include the score. testResetGame() now sets score = 500 before resetting, and checks it goes back to 0.

The new tests

testAliens = [makeAlienWorth(100, 30), makeAlienWorth(300, 10)];

Tests for a miss (0 points), one hit, and two hits in the same frame, which checks that the points add up rather than the second replacing the first.
