Game 01 — Drawing the Ship

Sketch: src/game/01-ship/sketch.js · Tests: src/game/01-ship/tests.js

The first stage with any game code: a Ship class, and one ship drawn near the bottom of the canvas. It doesn't move yet.

The class itself uses only what you know from 09-ball-class (a class with a constructor and a display() method) and 08-display-ball-function (translate(), push() and pop()). What's new is automatic testing in a separate tests.js file, and using the browser's debugger to pause the sketch and look inside it.
