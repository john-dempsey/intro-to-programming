Exercises

Working copy: exercises/game-01-ship/. Full instructions are in that folder's README.md. Keep the browser console open while you work.

  1. Predict, change, observe. Predict, then try: a wider ship, no margin, and rectMode(CORNER).
  2. Break it. Delete pop() and explain why it still looks fine for now. Make a test fail and read the message. Undo with git restore.
  3. Debugger. Set a breakpoint inside display(), inspect this, and work out why it pauses every frame.
  4. Write a test. Add a test function with two checks, and make each fail once on purpose.
  5. Bug hunt. bug-hunt/ has one planted bug. Use the failing test and the debugger to find and fix it.
  6. Git. Use git status and git diff to read your changes before committing.
  7. Your project. Build the smallest visible version of your stage 1, and commit it.
