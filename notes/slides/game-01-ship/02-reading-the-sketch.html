Reading the sketch

The Ship class

class Ship {
    // x and y are the centre of the ship's body.
    constructor(x, y, bodyWidth, bodyHeight, shipColour) {
        this.x = x;
        this.y = y;
        this.bodyWidth = bodyWidth;
        this.bodyHeight = bodyHeight;
        this.col = shipColour;
    }

    display() {
        let cannonWidth = this.bodyWidth / 5;
        let cannonHeight = this.bodyHeight / 2;

        push();
        translate(this.x, this.y);    // (0, 0) is now the ship's centre
        rectMode(CENTER);             // rectangles are positioned by their centre
        noStroke();
        fill(this.col);
        rect(0, 0, this.bodyWidth, this.bodyHeight);                                // body
        rect(0, -(this.bodyHeight + cannonHeight) / 2, cannonWidth, cannonHeight);  // cannon
        pop();
    }
}

This has the same shape as the Ball class from sketch 09. display() uses translate() so both rectangles can be drawn relative to (0, 0), as in the traffic-light example from sketch 08.

The cannon sits on top of the body. Its centre is half the body's height plus half the cannon's height above the ship's centre. That's -(this.bodyHeight + cannonHeight) / 2 (negative, because y goes up the screen as it gets smaller).

Creating the ship

ship = new Ship(width / 2, height - SHIP_MARGIN, SHIP_WIDTH, SHIP_HEIGHT, color(0, 220, 120));

runTests();

The ship starts in the middle (width / 2), SHIP_MARGIN pixels up from the bottom. The tests run once, at the end of setup(), after the ship exists.

The tests

function testShipConstructor() {
    let testShip = new Ship(100, 200, 50, 20, color(255));

    check("constructor stores x", testShip.x, 100);
    check("constructor stores y", testShip.y, 200);
    check("constructor stores bodyWidth", testShip.bodyWidth, 50);
    check("constructor stores bodyHeight", testShip.bodyHeight, 20);
}

function testShipStartPosition() {
    check("ship starts in the middle", ship.x, width / 2);
    check("ship starts near the bottom", ship.y, height - SHIP_MARGIN);
}

The first test builds its own ship, testShip, with simple numbers, and checks the constructor stored them. The second checks the game's real ship started in the right place. Each test is its own function, named after what it tests, so a failure points to the right area straight away.
