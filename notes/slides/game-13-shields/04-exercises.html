Exercises

Working copy: exercises/game-13-shields/. Full instructions are in that folder's README.md. Press D in the game: the overlay now draws every shield block's hitbox.

  1. Predict, change, observe. How many shots make a hole? Change the number and size of the shields.
  2. The console. Count the blocks as you shoot; look at a function's code; remove every shield at once.
  3. Break it. Change the order of the collision checks; break the shield spacing, then write a test that catches it.
  4. Debugger. One function, three jobs: use the Call Stack and Scope panels to see which job it's doing.
  5. Write a test. Bullets from both sides on the same block; why the old tests still pass.
  6. Bug hunt. Holes appear in the wrong places: two arrays, two indexes.
  7. Git. Make two unrelated changes to one file, and commit them separately.
  8. Challenge. Aliens that destroy the shields as they march through them.
  9. Your project. Is there code you've written two or three times that one function could replace?
