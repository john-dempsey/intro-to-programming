Game 13 — Shields

▶︎ Run this sketch Sketch: src/game/13-shields/sketch.js · Tests: src/game/13-shields/tests.js

Four shields between the ship and the aliens. Each shield is built from small square blocks, and a bullet from either side that hits a block destroys it, so the shields wear away during the game.

Bullets now have to be checked against shield blocks as well as aliens. Rather than write the collision code a second (and third) time, this stage changes it into one function that works with any list of targets. That kind of change, which improves the code without changing what the game does, is called refactoring, and the tests from stage 7 prove it worked. The exercises use the debugger to watch one function do three jobs, and show how to commit just part of a file.
