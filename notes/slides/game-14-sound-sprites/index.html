Game 14 — Sound and Sprites

▶︎ Run this sketch Sketch: src/game/14-sound-sprites/sketch.js · Tests: src/game/14-sound-sprites/tests.js

The ship and the aliens are now drawn with pixel-art images, called sprites, with three kinds of alien as in the original game. Shooting, destroying an alien and being hit each play a sound, and M turns the sound on and off.

This is the first stage that loads files: images and sounds from an assets folder. Files can go missing, so the game is written to carry on without them: it draws the old shapes, or stays silent.

New ideas: loading files in preload(); callbacks, functions you hand to another function to call later; looking things up by name in an object; why browsers won't play sound straight away; and testing sound without hearing it. The exercises use DevTools' Network tab and add a .gitignore file to your repository.

Running your own copy: the Run button above works, because this site is served by a web server. A copy opened straight from a folder can't load its files. Open your working copy with VS Code's Live Server extension instead (right-click index.html, then Open with Live Server).
