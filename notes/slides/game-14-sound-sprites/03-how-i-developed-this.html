How I developed this

Making the sprites

git switch -c sound-sprites

The sprites are small pixel-art images, drawn in white on a transparent background so the game can colour them with tint(). The images and the sound effects went in an assets folder next to sketch.js.

Nothing loaded

I double-clicked index.html as usual, and the page said "Loading..." and never started. The console was full of red errors about the files being blocked.

A page opened straight from a folder isn't allowed to load other files, for security. I started VS Code's Live Server instead, which serves the folder the way a real website would, and the sprites appeared. From this stage on, the game always runs through a server.

Stuck on "Loading..."

Then I tried a missing file on purpose, by renaming ship.png. The page was stuck on "Loading..." again: one missing image, and the whole game never started. My first version of loadSprite() only gave loadImage() the "it worked" callback. With nothing to call on failure, p5 waited for that file forever.

Adding the second callback, which prints a warning, fixed it: now a missing file is reported and the game draws shapes instead. I added testDrawingWithoutSprites() to make sure the shapes keep working.

A typo no test could see

Later, playing the game, the two middle rows of aliens were drawn as shapes, while the others were sprites. Every test passed. The console had the answer:

Couldn't load assets/alien-crabs.png, so shapes will be drawn instead

The file was alien-crab.png; I'd typed alien-crabs.png. DevTools' Network tab showed the same thing as a 404, "not found". The tests didn't catch it because they're written to pass with or without sprites, on purpose. Only looking at the game, and reading the console, could find this one. This is the stage's bug hunt.

The first shot was silent

With the sounds added, the first shot of every game made no sound, and the console said:

The AudioContext was not allowed to start. It must be resumed (or created) after a user gesture on the page.

That's the browser's rule about sound. Calling userStartAudio() at the start of keyPressed() fixed it.

Testing sound

I wanted a test that firing plays a sound, without the tests making a noise every time the page loads. Swapping the real sound for a fake that counts its plays did both.

Manual checks

  • With Live Server, the ship and aliens are sprites, each row in its own colour.
  • The pixel edges are sharp, not blurred.
  • Shooting, destroying an alien and being hit each play their sound.
  • M turns sound off (the screen says SOUND OFF) and on again.
  • With a sprite file renamed, that sprite is drawn as shapes and the console warns.
  • With a sound file renamed, the game is silent for that sound and the console warns.
  • The console shows only PASS lines.

The commits

git add assets
git commit -m "Add sprite images and sound effects"
git commit -am "Draw sprites, with shapes if they don't load"
git commit -am "Fix crab sprite file name"
git commit -am "Sound effects; M turns sound on and off"
git switch main
git merge sound-sprites
git branch -d sound-sprites

The images and sounds are new files, so they needed git add: git commit -am only includes files Git already knows about. git add assets adds everything in the folder, so it's worth a .gitignore file first, to keep out files the operating system makes, such as Thumbs.db on Windows.
