Reading the sketch

move() {
    this.x += this.vx;          // step forward, same as sketch 11
    this.y += this.vy;

    let radius = this.diameter / 2;   // local variable, this call only

    if (this.diameter > width) {          // edge case: too wide to bounce normally
        this.x = width / 2;
        this.vx = 0;
    } else if (this.x + radius > width) { // right edge collision
        this.x = width - radius;          // clamp position to the edge
        this.vx *= -1;                    // reverse direction
    } else if (this.x - radius < 0) {     // left edge collision
        this.x = radius;
        this.vx *= -1;
    }

    // the same three-way check, repeated for the vertical (y) axis
    if (this.diameter > height) {
        this.y = height / 2;
        this.vy = 0;
    } else if (this.y + radius > height) {
        this.y = height - radius;
        this.vy *= -1;
    } else if (this.y - radius < 0) {
        this.y = radius;
        this.vy *= -1;
    }
}

move() still steps the ball forward with plain +=, exactly as sketch 11 did (sketch 12's modulo wrap is gone). What's new is everything after: two independent if/else if chains — one for the x-axis, one for the y-axis — each checking, in order, "is this ball too big to fit?", then "has it crossed the right/bottom edge?", then "has it crossed the left/top edge?". Whichever one condition matches (if any) clamps the position and flips the relevant velocity.
