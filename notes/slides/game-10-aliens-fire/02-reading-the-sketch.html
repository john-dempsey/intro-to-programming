Reading the sketch

Off screen at either end

isOffScreen() {
    let pastTop = this.y + this.bulletHeight / 2 < 0;
    let pastBottom = this.y - this.bulletHeight / 2 > height;
    return pastTop || pastBottom;
}

Stage 3's exercises asked whether a bullet below the canvas should count as off screen. It didn't matter then. Now that bullets fall, it does.

The aliens fire

function maybeAlienFires() {
    if (aliens.length > 0 && random() < ALIEN_FIRE_CHANCE) {
        let shooter = random(aliens);
        alienFires(shooter);
    }
}

function alienFires(shooter) {
    let startY = shooter.y + shooter.alienHeight / 2 + BULLET_HEIGHT / 2;
    let newBullet = new Bullet(shooter.x, startY, BULLET_WIDTH, BULLET_HEIGHT, ALIEN_BULLET_SPEED, color(255, 80, 80));
    alienBullets.push(newBullet);
}

The bullet starts with its top edge just under the alien's bottom edge, mirroring how the player's bullets start at the top of the cannon.

Two arrays, one set of functions

moveBullets(bullets);
moveBullets(alienBullets);

moveBullets() and displayBullets() now take the array as a parameter, so the same code handles both. Before, they always used the global bullets.

Hit and lives

if (shipIsHit(alienBullets, ship.getBounds())) {
    lives -= 1;
    alienBullets = [];   // clear the screen, so the player has a moment to recover
}

gameState = checkGameState(aliens, ship.getBounds().top, lives);

shipIsHit() is the "is any...?" search again, with boundsOverlap() from stage 7. checkGameState() has a new parameter, livesLeft, and a new way to lose.

The new tests

function testAlienFires() {
    alienBullets = [];
    alienFires(makeTestAlien(100, 100));

    check("an alien firing adds one alien bullet", alienBullets.length, 1);
    check("the bullet starts just below the alien", alienBullets[0].y, 116);
    // ...
    alienBullets = [];
}

This tests the non-random half of firing. The test alien is 20 high, so its bottom is at 110; the bullet is 12 high, so its centre starts 6 lower, at 116.

testLoseWhenNoLives() also records a decision as a test: destroying the last alien in the same frame as losing the last life counts as a win.
