Game 10 — The Aliens Fire Back

How I developed this

Refactor first: velocity

On a new branch, before adding any alien firing, I changed Bullet from speed to vy. The game should behave exactly as before, so I ran the tests:

FAIL: bullet moves up by its speed (expected 292, got 308)

The tests still created bullets with 8, which now meant "8 pixels down". I changed the test helpers to -8, and searched for every new Bullet( to check the game's own bullets too. Once everything passed, I committed the refactor on its own. Then I started on the feature.

Bullets that never went away

The aliens fired, the bullets fell, and the game seemed fine. After a minute I turned on the debug overlay:

alien bullets in array: 71

The same problem as stage 4, upside down: isOffScreen() only checked the top, so falling bullets were never removed. Stage 3's exercises had asked exactly this question. I added the pastBottom check, and a test for it.

Three lives, one bullet

My first version of being hit was:

if (shipIsHit(alienBullets, ship.getBounds())) {
    lives -= 1;
}

The first time I was hit, the game ended. I set a breakpoint on lives -= 1 and it paused three frames in a row, with the same bullet each time, a little lower. A bullet takes several frames to pass through the ship, and every one of those frames cost a life. Clearing the alien bullets after a hit fixed it, and also gives the player a moment to recover.

Debugging something random

Some games felt much harder than others, and I wanted to check that the firing rate was right. Each game was different, so it was hard to compare. Adding randomSeed(1) to setup() while I tested made every game identical, as long as I didn't fire, so I could count shots and compare changes fairly. I removed it once I was done; with it, every game would be the same.

Manual checks

  • Aliens fire about once a second, from random aliens.
  • Alien bullets fall straight down and disappear at the bottom (overlay count goes back down).
  • Being hit loses exactly one life and clears the alien bullets.
  • Losing the third life ends the game with "GAME OVER".
  • Enter starts a new game with three lives.
  • The console shows only PASS lines.
