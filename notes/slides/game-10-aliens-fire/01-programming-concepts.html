Game 10 — The Aliens Fire Back

Programming concepts

A chance each frame

if (aliens.length > 0 && random() < ALIEN_FIRE_CHANCE) {

random() with no arguments returns a number from 0 up to (but not including) 1. It's below 0.02 about 2% of the time. draw() runs 60 times a second, so on average an alien fires 60 × 0.02 = 1.2 times a second, but at unpredictable moments.

random() given an array returns one item from it, chosen at random: random(aliens) picks the shooter.

The check aliens.length > 0 comes first. With no aliens left, random(aliens) would have nothing to pick. Because && stops as soon as one side is false, random() isn't even called when the array is empty.

Randomness makes testing harder

A test needs to know what result to expect, and random code gives a different result each time. Two ways round it are used here:

  • Split the random decision from the action. maybeAlienFires() decides whether and which, using random(). alienFires(shooter) does the firing, with no randomness, so it can be tested with a specific alien. (The same split as readDirection() and move() in stage 2.)
  • randomSeed() makes random() produce the same sequence of numbers every time the program runs. That's very useful for debugging: a bug that only happens "sometimes" happens the same way every run.

One class, two directions: velocity

Up to now, Bullet had a speed and always moved up. Alien bullets move down. Rather than writing a second, almost identical class, Bullet now has a vertical velocity, vy, exactly like vx/vy on the balls in sketch 11:

move() {
    this.y += this.vy;    // negative vy: up the screen; positive vy: down
}

The player's bullets are created with -BULLET_SPEED, the aliens' with ALIEN_BULLET_SPEED.

An event that should happen once

A bullet overlaps the ship for several frames as it passes through. If every one of those frames cost a life, one bullet would take all three. When the ship is hit, every alien bullet is removed, which ends the overlap straight away and gives the player a moment to recover.
