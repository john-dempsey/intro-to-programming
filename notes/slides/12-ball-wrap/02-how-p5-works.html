How p5 works

  • width/height used inside a calculation, not just as a one-off argument. createCanvas() set width and height back in sketch 01, and until now they've only been read once, by p5 itself, to size the canvas. Here they're read directly inside move()'s own arithmetic — a reminder that they're ordinary numbers, usable anywhere in the code, not values with some special restricted use.
