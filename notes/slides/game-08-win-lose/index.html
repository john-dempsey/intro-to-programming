Game 08 — Winning and Losing

▶ Run this sketch Sketch: src/game/08-win-lose/sketch.js · Tests: src/game/08-win-lose/tests.js

The game can be won (destroy every alien) or lost (an alien reaches the ship). When it ends, everything freezes behind a message, and Enter starts a new game.

That completes every "must have" feature in the plan: this is the smallest playable game. Everything after this improves a game that already works.

New here: a game state variable, constants for the states, and a resetGame() function. Adding them needed a refactor: separating the code that moves things from the code that draws them. The exercises show how to use the console to jump straight to the situation you want to test, and how to tag a milestone in Git.
