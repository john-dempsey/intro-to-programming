Game 02 — Moving the Ship

Exercises

Working copy: exercises/game-02-ship-moves/. Full instructions are in that folder's README.md.

  1. Predict, change, observe. Very fast and very slow ships; both keys at once. Do the tests notice a speed change?
  2. Break it. Remove the clamp; clamp the centre instead of the edge. Which tests catch each one?
  3. Debugger. Use a conditional breakpoint to pause only while a key is pressed, then only near the right edge.
  4. Write a test. Test the left edge after 1000 moves, and a ship with a different speed.
  5. Bug hunt. bug-hunt/ has one planted bug, the kind that's easy to make by copying and pasting.
  6. Git. Try keyPressed() on a branch, compare it with git diff main, then delete the branch.
  7. Your project. Write one check() for your own project, and look for input mixed in with logic.
