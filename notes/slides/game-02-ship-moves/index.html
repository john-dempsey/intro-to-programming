Game 02 — Moving the Ship

Sketch: src/game/02-ship-moves/sketch.js · Tests: src/game/02-ship-moves/tests.js

The ship moves left and right while an arrow key is held down, and stops at the edges of the canvas.

The clamping at the edges is the same idea as 13-ball-bounce. What's new is keyIsDown() for continuous movement, and a design decision: keeping the code that reads the keyboard separate from the code that moves the ship, so the movement can be tested. The exercises introduce conditional breakpoints and Git branches.
