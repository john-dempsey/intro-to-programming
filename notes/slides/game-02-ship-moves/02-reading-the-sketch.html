Reading the sketch

move()

// direction is -1 (left), 0 (stay still) or 1 (right).
move(direction) {
    this.x += direction * this.speed;

    let halfWidth = this.bodyWidth / 2;
    if (this.x - halfWidth < 0) {               // left edge of ship past left of canvas
        this.x = halfWidth;
    } else if (this.x + halfWidth > width) {    // right edge of ship past right of canvas
        this.x = width - halfWidth;
    }
}

Move first, then clamp: the same pattern as sketch 13, but only on the x-axis and with no change of direction. Because x is the ship's centre, its left edge is x - halfWidth and its right edge is x + halfWidth.

readDirection()

function readDirection() {
    let direction = 0;
    if (keyIsDown(LEFT_ARROW)) {
        direction -= 1;
    }
    if (keyIsDown(RIGHT_ARROW)) {
        direction += 1;
    }
    return direction;
}

Two separate ifs, not if/else if, so both keys are always checked. Holding both gives -1 + 1 = 0, and the ship stays still.

draw()

function draw() {
    background(BACKGROUND_COLOUR);

    ship.move(readDirection());
    ship.display();
}

Every frame: clear the screen, move, draw. readDirection() runs first and its result is passed straight into move().
