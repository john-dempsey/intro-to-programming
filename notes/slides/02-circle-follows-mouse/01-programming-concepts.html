Programming concepts

console.log() — printing a value to inspect it

console.log(mouseX, mouseY);

console.log() is a function (built into JavaScript itself, not p5) that prints whatever arguments it's given to the browser's developer console — a panel separate from the canvas, opened from the browser's dev tools. It doesn't affect what's drawn; it's a way to look inside a running program and check what values it's actually working with, rather than guessing from the visible output alone. This is the first debugging technique students meet, and one they'll reach for constantly: whenever the code isn't doing what's expected, printing a suspicious value is usually the fastest way to find out why.
